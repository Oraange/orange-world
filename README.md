# 🍊Orange World

This is a code bundle for Orange World. The original project is available at https://www.figma.com/design/cb4tLg1fJODerP0Fk3HX94/Create-My-TODO-List.

## 📋 Project Overview

개인 웹페이지 제작을 위한 프로젝트입니다.
또한 Express & Vite-React & Typescript 연습을 위한 프로젝트이기도 합니다.

## ✨ Features

- Home : 메인 페이지
- Todo : 나의 Todolist
- Portfolio : 개인 포트폴리오가 올라갈 페이지
- Games : 미니 게임 리스트

## 🚀 Getting Started

### versions

- Node.js v24
- npm v11
- vite 6.3.5

### Installation

```bash
# Clone the repository
git clone https://github.com/Oraange/orange-world.git

# Navigate to project directory
cd orange-world

# Install dependencies
npm install

# Start development server
npm run dev
```

### environment

```bash
# .env

VITE_DEV=true # Put your environment
VITE_API_BASE_URL=http://{your-url}:{your-port} # Put your url
VITE_SUPABASE_URL=https://{supabase-url} # 현재는 supabase BaaS로 서비스 중
VITE_SUPABASE_ANON_KEY={anon-key}
```

## 🛠️ Tech Stack

- Frontend Framework: Vite-React
- Styling: Tailwind CSS
- State Management: Local State만 관리 중
